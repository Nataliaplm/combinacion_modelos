# Combinación de modelos de Machine Learning

Práctica académica del **Máster Universitario en Ciencia de Datos (UOC)** sobre métodos de combinación de modelos de aprendizaje automático. El trabajo utiliza un dataset para explorar y comparar diferentes técnicas de clasificación:

* Modelos base
* Bagging y Random Forest
* Gradient Boosting
* Stacking y Cascading
* Balanced Random Forest
* Ajuste del umbral de decisión y análisis de costes

El objetivo es analizar cómo diferentes estrategias de combinación afectan al rendimiento del modelo y seleccionar la alternativa más adecuada teniendo en cuenta el coste de los errores de clasificación.

**Tipo:** Práctica académica · Machine Learning · Python
